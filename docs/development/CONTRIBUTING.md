# Contributing

## Rules

1. Start every change from [../README.md](../README.md), [../../AGENTS.md](../../AGENTS.md), and the relevant source-of-truth spec.
2. If behavior is missing or ambiguous in specs, update the spec before implementation.
3. Keep changes scoped to the current task.
4. Do not introduce dependencies unless justified by the task and accepted decisions.
5. Keep backend, frontend, tests, and documentation traceable to acceptance criteria.
6. Run relevant verification before completion.
7. Review the diff and remove temporary code or debug output.
8. Use [../plans/implementation-plan.md](../plans/implementation-plan.md) for implementation status and task readiness.

## Commit types

- `docs`
- `chore`
- `feat`
- `fix`
- `test`
- `refactor`

Suggested format: `type(scope): summary`.
